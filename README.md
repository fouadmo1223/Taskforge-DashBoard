# Taskforge Admin Dashboard

Platform-wide admin dashboard for Taskforge. A standalone frontend that talks to the
existing Taskforge-Back API, giving a platform administrator cross-workspace visibility
and control over users, workspaces, projects, tasks, and activity.

See [docs/PLAN.md](docs/PLAN.md) for the full architecture analysis and phased build plan
— that file is the source of truth for progress and should be updated as work continues.
